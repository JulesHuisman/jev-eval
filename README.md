# Jev Correctness Eval

Using the new Jev model in Deepeval to get better correctness scores.

## Setup

1) Make sure `uv` is installed.
2) Copy `example.env` to `.env` and fill the variables.
3) (Optional) Run `make synthesize` to generate a new evaluation set.
4) Run `make evaluate` to start the evaluation with the Jev correctness.
